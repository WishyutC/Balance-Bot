# Balance Bot — Baseline voice assistant

This branch (`segment/b-bots`) contains the original `b_bots/` directory at the repository root. Application source is preserved. This is an archived variant with known test failures; see the [verification report](docs/TEST_REPORT.md).

Run Python entry points from this repository root. See [setup](docs/SETUP.md), [version inventory](docs/VERSIONS.md), and [branch map](docs/BRANCHES.md). Model weights, virtual environments, logs, generated audio, and build output are excluded from Git.

Start the assistant with `python main.py`; start its dashboard API separately with `python pi_api.py`.
